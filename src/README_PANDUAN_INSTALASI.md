# 🌴 MASTER PROJECT: ULTRA REALISTIC TROPICAL HANGOUT WORLD — ROBLOX

Paket ini berisi seluruh kode sumber **16 Modul Lua Arsitektur Profesional** untuk membangun map **Tropical Paradise — Beach, Mountain, Waterfall & Garden Hangout** di Roblox Studio.

## 🚀 CARA INSTALASI PALING CEPAT (1-CLICK COMMAND BAR)
1. Buka **Roblox Studio** dan buat/buka tempat baru (**Baseplate** atau **Empty Baseplate**).
2. Hapus Part `Baseplate` bawaan jika ada agar tidak menutupi laut.
3. Buka file **`ONE_CLICK_STUDIO_INSTALLER.lua`** dari dalam ZIP ini, lalu **Copy seluruh isinya**.
4. Di Roblox Studio, buka tab **View** -> aktifkan **Command Bar** dan **Output**.
5. **Paste** script tersebut ke dalam **Command Bar** di bagian bawah layar dan tekan **Enter**.
6. Seluruh folder, 15 ModuleScript, dan Master Script akan otomatis terpasang di `ServerScriptService` DAN dunia **Tropical Paradise** langsung terbangun di `Workspace`!

## 📂 CARA INSTALASI MANUAL / ROJO
- Jika menggunakan **Rojo**, jalankan `rojo serve` pada folder hasil ekstrak ZIP ini.
- Jika manual:
  1. Buat Folder bernama `TropicalParadiseModules` di dalam `ServerScriptService`.
  2. Masukkan ke-15 file modul dari `src/ServerScriptService/TropicalParadiseModules/` sebagai `ModuleScript`.
  3. Buat `Script` bernama `WorldGenerator` di dalam `ServerScriptService` dan isi dengan kode `WorldGenerator.server.lua`.
